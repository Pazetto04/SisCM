# SisCM
Project of Software Test discipline on Computing Science corse Brasília's Catholic University
MAKE SURE NODE.JS IS INSTALLED
Tutorial below
1: Create a folder called 'public' and put the archive 'index.html' inside it
2: Open the code on VSCode
3: Open the terminal
4: Type the following commands on the Terminal: 
npm install
npm init -y
npm install express body-parser
5: a folder named 'node_modules' should appear and two archives named 'package.json' and 'package-lock.json' should appear also
6: on the terminal, type the command bellow
node index.js
7: The following message should appear right bellow it
'Servidor rodando em http://localhost:3000'
8: open your navegator and type on the top searchbar:
http://localhost:3000
9: the site should work correctly :)
WARINING
If you close the terminal, you will lose all the data inside it. Also no cyber security included on this project
